## Git and GitHub Workflow

### Repository

My course repository is [F26-ECSE395-jmf277](https://github.com/jmf277/F26-ECSE395-jmf277).

**Git** tracks changes in my local repository, while **GitHub** hosts the remote repository. I used *Visual Studio Code* to edit my Markdown files.

### Checking the Repository

The command `git status` shows the state of my local repository, including changes that have not yet been committed. The command `git remote -v` shows the configured remote addresses.

### Recording and Uploading Changes

- **Stage:** Select the changes to include in the next commit.
- **Commit:** Record the staged changes in the local repository's history.
- **Push:** Upload the commits to GitHub using `git push origin main`.

> Saving a file, committing changes, and pushing commits are separate steps. A saved change is not uploaded to GitHub until it has been committed and pushed.
